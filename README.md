# Restaurant-Website
A responsive and elegant restaurant website developed using HTML, CSS and JavaScript.

### Project Overview
This project is a modern and elegant restaurant website developed using front-end web technologies.
It provides visitors with an attractive interface to explore restaurant information, food menus, and other website sections.

### Features

Elegant website design.

Responsive layout.

Restaurant homepage.

Food menu section.

About section.

Reservation section (if implemented).

Food images and visual content.

### Technologies Used

HTML5

CSS3

JavaScript

Bootstrap5

### Project Structure

bsHome.html – Main webpage.

ss.css – Website styling.

sd.js – Interactive functionality.

images/ – Website images.

### How to Run
Download or clone this repository.

Open the project folder.

Open bsHome.html in your web browser.
